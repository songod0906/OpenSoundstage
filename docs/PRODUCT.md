# Product brief

## Product promise

OpenSoundstage gives Mac listeners a wider and more coherent system mix. It
starts with one action. It leaves no permanent audio route behind.

## Primary user

The primary user listens to music for long periods on a Mac. The user often
uses Bluetooth headphones. The user wants a full stereo image and clear
control. The user rejects unstable routes, hidden helpers, and repeated audio
daemon restarts.

## Job to be done

When I listen to music on my Mac, help the mix feel wide, complete, and lively
without making my audio setup fragile.

## User outcomes

- Hear a clear improvement in the first minute.
- Start and stop processing without audio troubleshooting.
- Keep the selected sound after an app restart.
- Change output devices without manual route repair.
- Understand what the app stores and controls.

## Product principles

1. Reliability is a feature.
2. Audio stays on the Mac.
3. One control has one clear effect.
4. The app owns and cleans up its route.
5. Defaults must sound useful at a safe level.
6. Evidence decides release readiness.

## Current scope

- One native macOS app
- Three sound presets
- Five direct sound controls
- One temporary private route
- Local product health counters
- Bluetooth and built-in stereo output support

## Not in the first release

- Cloud accounts
- Remote analytics
- Audio recording
- Per-app routing
- Speaker-room correction
- Automatic headphone calibration

## Release outcome

Version 0.1 proves that the route and core sound can support daily listening.
Version 0.2 will follow measured user friction. It will not follow a feature
count target.
