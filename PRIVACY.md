# Privacy

OpenSoundstage processes audio on the Mac. It does not send audio or analytics
to a server.

## Local product health data

The app stores these counters in the application defaults domain:

- First launch time
- App launch count
- Sound start attempts
- Successful and failed starts
- Completed session count
- Total enhanced seconds
- Output change count
- Last route failure category

The report does not store audio, output names, file names, app names, network
addresses, account data, or personal identifiers.

Select **Product health** in the app to view the counters. You can copy the
report for a support request. You can reset the counters at any time.

## System audio permission

macOS controls system audio permission. OpenSoundstage uses the permission only
to process the active system mix. The app does not record the mix to a file.
