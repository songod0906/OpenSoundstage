# Support

## First checks

1. Stop other system audio processors.
2. Confirm that macOS uses the intended output device.
3. Confirm that macOS granted system audio access.
4. Stop sound in OpenSoundstage.
5. Start sound again.

Do not restart `coreaudiod` as the first action.

## Report a problem

Open a GitHub issue. Include the macOS version, Mac model, output connection
type, steps, expected result, and actual result. Copy the local product health
report if it helps reproduce a route problem.

Do not attach private audio or unrelated system logs.
