# Security policy

## Supported version

The latest release receives security fixes.

## Report a problem

Open a GitHub security advisory for the repository. Do not put an active
security problem in a public issue.

Include these items:

- The affected version
- The macOS version
- The output device type
- The steps that reproduce the problem
- The expected result
- The actual result

Do not include account credentials, private audio, or unrelated system logs.
